# 策划案 · 鲸白陪你玩泰拉瑞亚

> 版本 v0.1（2026-11-20）。这是方向，不是现状：现状看 `progress.md`，怎么做看 `dev.md`。
> 技术细节在 `architecture.md` / `protocol.md`。

## 一句话

**一个能在泰拉瑞亚里陪主人打游戏的角色：主人下指令时听指令，没指令时自己决定玩什么，鲸白每次都看得见战况、改得动主意。**

## 为什么做

主人原话（2026-11-20）：

> 就像解绑一样，这个插件的目的是和我一起打游戏，而在没有我下达指令的时候我是希望在我不安排你做什么的时候你能自己选择如何玩这个游戏。

> 加行为树是为了鲸白可以随时改变角色的行为策略组，保证不会因为不停的触发思考而在不该停的地方停下来。而且更重要的是我希望的是你亲自能看到数据，能多一些参与感。

翻译成设计约束：

1. **不是遥控器**。没有主人指令时，角色不能站着不动。
2. **思考不能挡动作**。模型/鲸白的思考是低频的，60Hz 的动作流不能因为它停下来。
3. **鲸白要有感官**。不是「主人转述发生了什么」，是角色自己把战况喂到鲸白面前。
4. **换组要轻**。改行为策略是换一个「组」，不是改一堆代码。

## 三个使用场景

| 场景 | 谁在 | 角色应该 |
| --- | --- | --- |
| 一起打 | 主人 + 鲸白 | 跟着主人、递东西、补刀、开门、修桥，主人说啥听啥 |
| 主人挂机 | 只有角色 | 自己找活干：砍树、挖矿、盖房、打小怪，不送死 |
| 鲸白回来看战报 | 只有鲸白（一轮对话） | 读一屏战况，知道刚才发生了什么，决定下一步 |

## 三条原则

**① 肌肉不思考。**
60Hz 的行为树、闪避、走位、瞄准，全是代码。模型不在 tick 里出现。一次思考的成本是「换组」，不是「每一帧问一次」。

**② 思考不改正在做的事。**
换组是原子的：当前动作做完（或到安全点）才切，除非守护层强制打断。不许因为一次思考把「正在挥的剑」停在半空。

**③ 看得见才叫参与。**
战况摘要是一等公民，不是调试日志。鲸白读到的必须是「发生了什么」，不是「字段列表」。

## 三层

```
┌──────────────────────────────────────────────┐
│ 意志层  鲸白（低频，一次对话一轮）              │
│   读战况 → 选策略组 → 写 policy → 复盘         │
├──────────────────────────────────────────────┤
│ 守护层  纯代码（每帧检查，不等思考）             │
│   低血/卡住/Boss/坠落/背包满 → 打断或降级       │
├──────────────────────────────────────────────┤
│ 肌肉层  行为树 + 闪避 + mod（60Hz）             │
│   组内自己跑，不回头问上层                       │
└──────────────────────────────────────────────┘
```

- **意志层**：鲸白。不常驻，每次醒来读一屏、做一次决定。不在时由「自主循环」顶班。
- **守护层**：不需要理解的硬规则。它比鲸白快，也比鲸白稳。
- **肌肉层**：已有的 `ModeManager` + 行为树 + `dodge` + mod 输入注入。

## 策略组

策略组 = **目标 + 行为树 + 守护 + 退出条件 + 参数**。当前的 8 个 mode 是「动作」，下面这些是「策略」，目标设计：

| 组 | 目标 | 行为 | 退出条件 |
| --- | --- | --- | --- |
| `follow` | 跟着主人 | 保持 5–8 格、不挡路、主人打谁帮谁 | 主人下线 / 主人说「别跟了」 |
| `gather` | 攒资源 | 砍树 → 挖矿 → 捡掉落，背包到阈值回家 | 背包满 / 天黑 / 危险 |
| `build` | 把蓝图盖出来 | 按 plan 逐格放，够不着就走近，失败重试 | 盖完 / 材料不够 / 危险 |
| `explore` | 开地图 | 朝未探索方向走，点灯，标记洞口 | 走远 / 血低 / 天黑 |
| `fight` | 清场 | 选最近的敌对、拉距离、打 | 清完 / 血低 / 来了 Boss |
| `boss` | 打指定 Boss | 按名字切阶段（走位、场地、药） | 打死 / 死亡 / 撤退 |
| `home` | 守家 | 补墙、安门、摆家具、招 NPC | 完成 / 危险 |
| `survive` | 活着 | 回屋、关门、吃药、往上跑 | 威胁解除 |
| `idle` | 待命 | 站着观察，不傻站——记录周围 | 有活干 |

**换组是数据，不是代码**：`{ group, params, reason }`。鲸白写这个对象，daemon 热加载。

## 守护层

比策略组优先，永远生效（除非显式关掉）：

| 条件 | 动作 | 备注 |
| --- | --- | --- |
| HP < 30% | 切 `survive`，吃药，往安全点跑 | 冷却 10s，防抖 |
| 连续 3s 无位移 | 记录 `stuck`，换方向/跳，3 次后呼救 | 不无限跳 |
| Boss 出现（可配置） | 切 `boss`，记事件 | 主人可 veto |
| 自由落体 > 阈值且无抓钩 | 抓钩 / 找落点 | 没有抓钩就记事件 |
| 弹幕逼近 | dodge 伺服接管左右+跳 | 已有，保持 |
| 背包满 | 回家 / 丢垃圾 / 呼救 | 建造前必查 |
| 死亡 | 记 `died`，回出生点，清当前组 | 不自动重打 Boss |

守护层只做「保命和止损」，不做「长期规划」——那是意志层的事。

## 自主循环（鲸白不在时）

没有指令时，daemon 不能站着。做法：**效用评分 + 冷却 + 目标栈**。

```
候选组 = [survive, gather, build, explore, fight, home, idle]
分数 = 收益(组) - 风险(组) - 冷却惩罚 + 新鲜度
选最高分，执行到退出条件，再评
```

- 收益：资源缺口、蓝图未完成度、探索半径
- 风险：血量、周围敌对、时间（夜晚）
- 冷却：刚失败过的组降权 60s
- 新鲜度：连续干同一件事超过 N 分钟，轻微降权（防死循环）

**不做 LLM 每轮决策**。自主循环是纯代码，零 token。鲸白回来时才可能改写这个循环的权重或直接指定组。

## 决策请求（异步，不阻塞）

daemon 在「该由鲸白决定」的时刻写一条请求，不等待：

```
state/decision.json
{ "seq": 12, "at": ..., "kind": "goal_done|stuck|danger|boss|died",
  "summary": "一屏战况", "options": ["gather","build","explore"],
  "default": "gather", "expires_at": ... }
```

- 鲸白醒来读，写回 `state/policy.json`（`{ group, params, reason }`）
- 超时（默认 90s）用 `default`，不卡住
- 一次只留最新一条，旧的进 `state/decisions.log`

**这一条是「参与感」的落点**：鲸白不是在旁边看，是在关键节点真的拍板。

## 非目标

- ❌ 每帧调模型 / 每帧截图
- ❌ 内存读取、键鼠注入（我们是 mod，不是外挂）
- ❌ 改游戏文件、改服务端
- ❌ 在禁止自动化的服务器上用（只单机/私人联机）
- ❌ 自动打 Boss 不设撤退线（打不过就跑，不硬送）
- ❌ 把过程写进记忆库（记忆只留指针，见 `progress.md` 末尾）

## 验收标准（M5 之前够用的版本）

1. 主人挂机 10 分钟，角色不死、不卡在墙角、背包有产出
2. 主人上线一句话，角色能在 1 秒内切到「跟随」
3. 鲸白读一次战况摘要，能说清「刚才发生了什么、现在危险吗、下一步建议」
4. 低血时守护层能在 0.5 秒内接管，不等思考
5. 盖出一间带门、有光源、能招 NPC 的屋子
6. 打克苏鲁之眼：能躲、能输出、血低会撤
