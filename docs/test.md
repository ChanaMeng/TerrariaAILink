## 4. 回归清单（每次改 mod 或 daemon 后过一遍）

1. 起 daemon → `link_up`，`brief` 有玩家坐标
2. `mv left` / `mv right` 各 0.5s → 位移方向正确
3. `say 测试` → 游戏聊天可见
4. `grid` → 瓦片不是全 `?`
5. 切 `idle` → 角色停住，不再发输入
6. 停 daemon → 角色松手（15 tick 后释放）
7. 重进世界 → 能重连，不残留旧组

## 6. 已知不可测 / 不能测

- **声音**：没有音频通道，任何「听到」都是推断。
- **连续动作的观感**：只能看抽帧，不能判断「手感」。
- **多人延迟**：本地回环，测不出公网延迟。
- **禁自动化服务器**：不测，也不该用。
